Controller map
  • Right stick → : start / end episode · Right stick ← : back
  • Left stick ↑ / ↓ : next / previous episode
  • A / X held : arm follows the ghost gripper (clutch)
  • Trigger : close / open gripper · Grip held : show that wrist camera
  • Touch thumb rest + move : move the ghost gripper (yellow dot = fixed point); B / Y : reset it
  • Thumb rest touched: bring the controller to a bar (top Force 5-120 N, bottom Width 0-83 mm, lights up within 6 cm) + hold grip; move the hand right = more, left = less (20 cm = full range); let go of grip = value stays (a touch that used a slider does not move the ghost); the panel and the yellow dot disappear as soon as the thumb leaves the rest (or when grip is released if a slider is still held); ?gripper=rubber_hand shows the rubber hand instead (no sliders)
  • Both sticks pressed + move hands : move / turn / scale the whole scene (50-200 %); the robot's feet go onto the real floor and stay there (green ring = on the floor, HUD shows the height); also hold a grip for up / down (snaps to the floor within 3 cm); press both twice : reset
  • Left stick press (L3) alone : show / hide the point cloud (server --cloud-file or --cloud-live)
